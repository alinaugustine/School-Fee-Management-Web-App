# School-Fee-Management-Web-App
A full-stack, AI-assisted school fee management system built using Google Apps Script, Google Sheets, and the Google Workspace ecosystem to digitize student fee collection, financial tracking, and administrative workflows.

## Overview

This project replaces manual spreadsheet-based fee tracking with a centralized web application that enables administrators to manage students, record payments, generate reports, and maintain accurate financial records from a single interface.

Designed for small and medium-sized educational institutions, the system emphasizes automation, usability, auditability, and low operating cost while leveraging Google's cloud infrastructure.

## Features

* Student registration and profile management
* Fee collection and payment recording
* Receipt generation
* Outstanding balance tracking
* Financial reporting dashboards
* Search and filtering
* Duplicate record validation
* Transaction history
* Administrative controls
* Google Sheets as the backend database
* Role-based workflows
* Automated calculations and validations
